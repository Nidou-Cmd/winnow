Questions Fréquentes

Tout ce que vous devez savoir sur Winnow

Une ingénierie FinOps sécurisée, instantanée et 100% orientée métadonnées.

L'audit en lecture seule est-il sans danger pour ma production ?

100% Zero-Trust. Nous n'interrogeons que les métadonnées (noms de métriques, tags, fréquences) via les API en lecture seule ou vos fichiers Terraform. Vos identifiants ne sont jamais persistés dans une base de données.

Comment fonctionne le mode Zéro-Clé Terraform ?

Vous chargez ou collez simplement vos manifestes Terraform (.tf). Notre moteur analyse les blocs d'index de logs et de métriques pour chiffrer les gisements d'économies sans jamais se connecter à Datadog.

Combien de temps prend l'audit ?

Moins de 60 secondes. L'analyse est instantanée pour le mode Terraform et prend environ 30 à 45 secondes pour une infrastructure complète en direct.

Puis-je exécuter Winnow dans mon propre réseau privé (In-VPC) ?

Oui. Pour les banques et environnements régulés, nous fournissons un chart Helm et une image Docker prêts à l'emploi avec zéro exfiltration externe.
